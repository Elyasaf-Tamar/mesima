# פתקים מהירים — אפיון (משימה 4.9.3)

## מטרה
לרשום מחשבה בכמה שניות ולצאת, כמו בקבוצת WhatsApp פרטית. אחר כך כל פתק הופך למשימה, נשמר כמידע או מועבר להערה. אסור שפתק ייעלם מהזיכרון: מה שלא סודר חוזר למשתמש.

## היקף 4.9.3 (קוד ווב + Windows בלבד, בלי APK חדש)
- לשונית רביעית בשם "פתקים", עם מונה של פתקים שלא סודרו.
- מסך בסגנון צ׳אט: בועות מלמטה למעלה, מפרידי תאריך, תיבת כתיבה קבועה בתחתית.
- פתיחה מאפס (cold start) נכנסת למסך הפתקים. אפשר לכבות את זה בהגדרות.
- זיהוי תאריך ושעה בעברית בתוך הטקסט, שמוצג כתגית ואפשר לבטל.
- לחיצה ארוכה, או קליק ימני במחשב, פותחת תפריט: הפוך למשימה, סמן כמידע, העבר להערה, ערוך, העתק, מחק (עם ביטול).
- תגיות #, חיפוש, וסינון: הכול, לסדר, מידע.
- מיון במסך "היום":
  - כרטיס "N פתקים לסדר", שנפתח למצב מיון של פתק אחד בכל פעם.
  - תזכורת מיון יומית בשעה שנבחרה. ב־Windows היא מגיעה כהתראת מערכת. ב־Android היא מופיעה רק בתוך האפליקציה עד שתצא מעטפת חדשה.

## מחוץ להיקף (לגרסאות הבאות)
- חלון כתיבה מהיר native ב־Android, שלא מחכה ל־WebView.
- ווידג׳ט "כתוב", אריח בהגדרות המהירות, ושיתוף מאפליקציות אחרות.
- קיצור מקלדת גלובלי ב־Windows.
- התראת מיון ברקע ב־Android (דורשת APK).

## נתונים
אוסף חדש `captures` ב־Store, שמסונכרן כמו שאר האוספים:
```
{ id, text, createdAt, updatedAt,
  state: 'inbox' | 'info' | 'task' | 'note',
  taskId?, noteId?,           // קישור אחרי המרה
  noDate?: true }             // המשתמש ביטל את זיהוי התאריך
```
- תגיות ותאריך מחושבים מהטקסט בזמן הצגה, ולא נשמרים. כך אין כפילות שיכולה להתפצל בין המכשירים.
- מחיקה מוחקת את הרשומה. הסנכרון שומר סימון מחיקה.
- הוספת `captures` לרשימת האוספים בסנכרון. לקוח 4.9.2 עוצר את הסנכרון מול רשומה מאוסף לא מוכר, בלי לדרוס נתונים. לכן צריך לעדכן את כל המכשירים.

## מפענח עברית (`CaptureParse`)
הוא מזהה את מה שמופיע בטבלה, ומחזיר `{date:'YYYY-MM-DD', time:'HH:MM'|null, uncertain, index, length, label}`.

| סוג | דוגמאות |
|---|---|
| ימים יחסיים | היום, הערב, מחר, מחרתיים |
| ימי שבוע | ביום ראשון, יום ב׳, בשבת, ובוא ראשון. יום שכבר עבר השבוע עובר לשבוע הבא |
| תאריך | 25/11, 25.11, 25/11/2026 |
| יחסי | בעוד N ימים, בעוד שבוע, בעוד שעה, בעוד N שעות, בעוד N דקות |
| שעה | ב־5, ב-17:30, ב 8, בשעה 9 |
| חלקי יום | בבוקר (09:00), בצהריים (13:00), אחה״צ (16:00), בערב (20:00), בלילה (22:00) |

- שעה 1–7 בלי ציון בוקר או ערב נחשבת אחר הצהריים, ומסומנת `uncertain`.
- שעה בלי יום: אם השעה עוד לא עברה היום, התאריך הוא היום. אחרת מחר.

## ממשק
- **שליחה:** Enter שולח, Shift+Enter מוסיף שורה. בטלפון כפתור השליחה שולח.
- **טיוטה:** טקסט שלא נשלח נשמר ב־localStorage של המכשיר ולא מסונכרן.
- **בועה:** טקסט, שעה, תגית תאריך (לחיצה עליה מבטלת את הזיהוי), ותגיות #.
- **מראה לפי מצב:**
  - "מידע": צבע נייטרלי.
  - "משימה" או "הערה": מעומעמת, עם קישור.
- **"הפוך למשימה":** פותח את עורך המשימות הקיים, עם כותרת (הטקסט בלי הביטוי של התאריך), תאריך ושעה. הפתק מסומן כמשימה רק אחרי שמירה מוצלחת, באותה עסקה.
- **"העבר להערה":** בוחרים הערה קיימת (הטקסט מתווסף בסופה) או יוצרים הערה חדשה.
- **מצב מיון:** מוצג פתק אחד בכל פעם, עם הכפתורים משימה, מידע, להערה, מחק ודלג.

## תזכורת מיון
- **הגדרות:** `prefs.captureReview` (ברירת מחדל `'20:30'`, או `''` לכבוי) ו־`prefs.captureStart` (ברירת מחדל true).
- **ב־Windows:** `Native.buildAlarms` מוסיף `cap_<day>` להיום ולמחר, רק כשיש פתקים לסדר. הרשימה עוברת לתזמון של Windows, שכבר קיים. לחיצה על ההתראה פותחת את מצב המיון דרך `window.__alarm`.
- **ב־Android 1.8.2:** המעטפת משתמשת ב־alarmPlan, ולכן לא מקבלת את הרשומה. במקום התראה יש כרטיס במסך "היום" ומונה על הלשונית.

## בדיקות
- בדיקות יחידה למפענח, כולל שעה בלי ציון, יום שעבר, סוף חודש וסוף שנה.
- בדיקות יחידה לסנכרון של `captures`: הוספה במקביל משני מכשירים, מחיקה, ושינוי מצב.
- בדיקות ל־Store: הוספה, שינוי מצב, ונרמול גיבוי ישן בלי `captures`.
- בדיקות התזכורת: `cap_` מופיע רק כשיש פתקים לסדר ותזכורת מופעלת.
- תרחיש ממשק ב־Playwright: כתיבה, שליחה, מיון ושמירה של הפתק כמשימה.
