# Firebase — הגדרה ואימות

תצורת Firebase המקומית אינה כלולה במאגר. קובצי הכללים כאן הם המקור לפרסום; שינוי שלהם ב־Git אינו מעיד שהכללים בפרויקט הפעיל כבר עודכנו.

## כללי 4.9.2

- גישה לנתונים מוגבלת ל־`users/{uid}` של המשתמש המחובר.
- יצירת גיבוי דורשת מזהה, נתיב, SHA-256, גודל וסוגי שדות תקינים. מספר הגרסה יכול להיות מספר תקין כמו 4.6 או 4.9.2, במקום רשימת גרסאות ישנות קבועה.
- קובצי גיבוי וסנכרון הם JSON בגודל של עד 20 MiB. יצירה דורשת `resource == null`; אין החלפה של תוכן בקובץ קיים.
- מסמך המצביע `sync/state` נשאר בגרסה 1. גרסה 2 מתייחסת לתוכן קובץ הסנכרון שאליו המצביע מפנה.

## בדיקה מקומית

מתיקיית השורש, עם Node 22 ו־JDK 17 מלא:

```sh
npm ci
npm run test:rules
```

הפקודה משתמשת בפרויקט אמולטור `demo-mesima`. היא אינה זקוקה למפתח שירות, לסיסמה או לחשבון Firebase פעיל. הבדיקות כוללות משתמש בעלים, משתמש אחר, משתמש לא מחובר, כתיבה חוזרת ומגבלת גודל.

## פרסום לפרויקט הפעיל

לאחר בחירת הפרויקט הנכון ואימות התיקונים:

```sh
npx firebase deploy --config firebase/firebase.json --project YOUR_PROJECT_ID --only firestore:rules,storage
```

הפרסום דורש הרשאות לחשבון Firebase של הפרויקט. יש להפעיל Authentication עם Email/Password ולהגדיר Firestore ו־Storage בהתאם לפרויקט. קובץ `android/app/google-services.json` נלקח מהגדרות האפליקציה `il.mesima.app`; אין להוסיף אותו לארכיון המקור הציבורי. Windows יכול להשתמש בתצורה נגזרת מאותו קובץ או בתצורה חיצונית מפורשת.

מסמכי ההקמה של 4.6 מתארים את ההקמה ההיסטורית. הוראות מעבר הסנכרון נמצאות ב־[מדריך 4.9.2](../README-4.9.2-HE.md).
