# משימה 4.7.1 — התקנה ושימוש

גרסת תיקון זו ממשיכה את 4.7. היא מתקנת את שגיאת Failed to fetch בסנכרון האוטומטי. הוראות התיקון והבדיקה נמצאות ב־SYNC-FIX-4.7.1-HE.md. שם האפליקציה נשאר משימה; בשיחת התכנון הוצעו שמות חלופיים, אך עדיין לא נבחר שם חדש.

## התקנה בטלפון

1. צור גיבוי ידני בגרסה הקיימת.
2. העבר לטלפון את `Mesima-4.7.1-Android-1.6-Firebase.apk` ופתח אותו.
3. התקן כעדכון מעל משימה הקיימת. אין להסיר את האפליקציה הישנה. נשמרו שם החבילה ומפתח החתימה המקורי.
4. פתח את האפליקציה פעם אחת, כדי להעביר את הנתונים העדכניים למנגנוני ההתראות, המיקום והווידג׳טים.
5. בדוק בהגדרות שמופיעה גרסת דף 4.7.1 ומעטפת Android 1.6. עדכון HTML בלבד אינו מתקין את יכולות Android החדשות.

## התקנה במחשב

1. חלץ את `Mesima-4.7.1-Windows.zip` לתיקייה חדשה.
2. צא מהגרסה הקודמת דרך תפריט **משימה → יציאה**, כולל הסמל ליד השעון.
3. פתח את `Mesima-win32-x64/Mesima.exe`. יש לשמור את כל התיקייה יחד.
4. אפשר להריץ את `Install-Mesima.ps1` באמצעות PowerShell כדי להעתיק את האפליקציה לתיקיית התוכניות האישית וליצור קיצורי דרך. אין צורך בהרשאות מנהל. המתקין לא הופעל אוטומטית במחשב שלך.
5. נתוני המחשב נשארים באותו מיקום של 4.6. אפליקציית Windows עדיין אינה חתומה בתעודת הפצה מסחרית, ולכן Windows עשוי להציג הודעת מפרסם לא מזוהה.

הממשק משתמש כעת ברוחב החלון. פסי הגלילה דקים וכהים; גלילה מופיעה רק היכן שהתוכן מצריך אותה. אפשר למקסם את החלון או לבחור **תצוגה → מסך מלא**.

## מה השתנה

- **משימה משותפת:** פתח משימה קצרה קיימת → ערוך משימה → שייכת ל. סמן את המשימות ארוכות הטווח הרצויות ושמור. קיימת משימה אחת עם כמה שיוכים, תיאור אחד, השלמה אחת ותזכורת אחת. ב״היום״ היא מופיעה פעם אחת. סגירת פרויקט אחד אינה מסיימת אותה כל עוד יש לה פרויקט פעיל אחר; מחיקת פרויקט מסירה את השיוך אליו ומשאירה אותה אצל ההורה האחר.
- **גרירה:** החזק את המשימה או תת־המשימה כחצי שנייה, גרור למיקום אחר ושחרר. האייקון הקודם הוסר. תנועה לפני סיום ההחזקה משאירה את מחוות הגלילה הרגילה. אפשר עדיין להשתמש בפעולות שינוי הסדר מהתפריטים.
- **הרחבת תתי־משימות:** לחיצה על ״ועוד…״ פורסת את כל הילדים בתוך כרטיס המשימה. ״צמצם תתי־משימות״ מחזיר את התצוגה הקצרה. לחיצה על שם המשימה פותחת את חלון הפרטים.
- **היום:** לחיצה על ״היום״ בשורת המצבים או בניווט התחתון מחזירה לתאריך הנוכחי.

## התראות עם תיאור וסימון ביצוע

כתוב את הברכה או הטקסט הרצוי בשדה **תיאור** של המשימה. התראת Android מציגה אותו במצב המורחב; אפשר להרחיב את ההתראה באמצעות החץ או המחווה שמציע הטלפון. מספר השורות שאפשר לראות נקבע גם בידי Android והמכשיר. לחיצה על ההתראה פותחת את התזכורת באפליקציה עם התיאור המלא, ומשם אפשר לפתוח את פרטי המשימה.

בתזכורת של משימה קצרה נוסף **בוצע**, לצד דחייה ברבע שעה והבנתי. **הבנתי** מסלק את ההודעה בלבד. **בוצע** מסיים משימה רגילה או מסמן משימה חוזרת להיום.

אם להרגל יש כמה שעות תזכורת, סימון ביצוע מבטל את יתר התזכורות לאותו יום ב־Android וגם מסיר הודעות קיימות. שעות היום הבא נשמרות. השלמה מתוך הווידג׳ט או מתוך ההתראה נשמרת גם כשהדף סגור, ונכנסת למסד הנתונים של האפליקציה בפתיחה הבאה. הסנכרון למחשב מתרחש כשהאפליקציה בטלפון פתוחה, כפי שהיה ב־4.6.

חלון תזכורות השעה שנמסר למערכת נותר שבעה ימים קדימה, עד 100 מופעים. פתיחת האפליקציה מרעננת אותו; זו אינה מערכת תזמון בלתי מוגבלת ללא פתיחת האפליקציה.

## מיקום ונסיעה ברקע

1. שמור תזכורת מסוג מיקום או נסיעה ואפשר את הרשאות המיקום וההתראות שהאפליקציה מבקשת.
2. בהגדרות Android של משימה, בחר **מיקום → אישור כל הזמן**, והפעל מיקום מדויק. באפליקציה, מתג מעקב המיקום נמצא תחת הגדרות → מתקדם → התנהגות האפליקציה.
3. כשהמעקב פעיל מופיעה הודעה קבועה: **תזכורות מיקום ונסיעה פעילות**. זהו סימן ששירות המיקום ממשיך לעבוד גם לאחר סגירת החלון.
4. אם המכשיר מגביל את משימה ברקע, בטל את הגבלת הסוללה עבורה דרך הגדרות המכשיר.

מרחק הנסיעה ומזהה הנסיעה נשמרים במכשיר. סגירת הדף או חוסר קליטה אינם מאפסים אותם. נסיעה חדשה מתחילה לאחר שנמדדה עצירה של כשש דקות ולאחריה חזרה לתנועה. הפסקה בקבלת מיקום לבדה אינה נחשבת לעצירה. נקודות לא מדויקות וקפיצות בלתי סבירות מסוננות. אין שמירה של מסלול מלא בענן.

מעקב רציף צורך סוללה. כיבוי מתג המיקום באפליקציה מפסיק אותו. **עצירה כפויה** של האפליקציה בהגדרות Android, כיבוי מיקום או שלילת הרשאות מונעים מעקב עד להפעלה מחדש; יצרנים מסוימים מגבילים גם שירותי רקע.

## חיפוש ושמירת מקומות

פתח **תפריט → מקומות**, הקלד שם עסק ויישוב, לדוגמה **סטימצקי, גן שמואל**, ולחץ חפש. אפשר למלא את העיר גם בשדה נפרד. בחר תוצאה, בדוק את הנקודה במפה ושמור. המקום זמין לאחר מכן בבחירת תזכורת מיקום במשימה.

החיפוש החדש שומר את הטקסט והתוצאות גם בזמן רענוני מיקום וסנכרון. Android ו־Windows פונים לשירותי המפות באמצעות המעטפת שלהם. תוצאה ריקה ושגיאת חיבור מוצגות בנפרד. אפשר לשמור מיקום נוכחי, לערוך קואורדינטות או להדביק קישור מפה הכולל קואורדינטות. קישור מקוצר שאינו מכיל קואורדינטות אינו מפוענח.

הנתונים מבוססים על OpenStreetMap דרך Nominatim, Photon ו־Overpass. הכיסוי אינו כולל כל עסק, וחיפוש דורש אינטרנט. הסניף המבוקש בגן שמואל משלים את נתוני המפות לפי [רשימת הסניפים הרשמית של סטימצקי](https://www.steimatzky.co.il/storelocator). אין צורך במפתח מפות חדש.

## וידג׳טים של Android

1. לאחר פתיחת גרסה 4.7.1, חזור למסך הבית של הטלפון.
2. לחץ לחיצה ארוכה על אזור ריק → **וידג׳טים**.
3. חפש **משימה** ובחר **משימות היום** או **יומן**.
4. גרור למסך הבית ושנה את גודלו לפי הצורך.

**משימות היום:** מציג משימות מתוכננות, הרגלים וצ׳קליסטים פעילים מתוך האפליקציה. לחיצה על הריבוע משלימה משימה קצרה; לחיצה על הכותרת פותחת אותה. צ׳קליסט נפתח באפליקציה כדי לסמן את פריטיו. סימון אינו דורש חיבור לאינטרנט.

**יומן:** מציג את אירועי שבעת הימים הקרובים, עם תאריך ושעה. לחיצה פותחת אירוע. כפתור + פותח יצירת אירוע חדש; בווידג׳ט המשימות הוא פותח יצירת משימה.

הווידג׳טים ניתנים לשינוי גודל וגלילה. אין מסך הגדרות נוסף. הם משתמשים בעותק מקומי שהאפליקציה מעדכנת בכל שינוי, ובתור פעולות שנשמר עד שהאפליקציה מאשרת שקיבלה אותו. תצוגת הימים מוכנה ל־42 ימים קדימה; לאחר מכן מוצגת בקשה לפתוח את משימה לעדכון. מעבר יום יכול להתעדכן בהשהיה של עד כחצי שעה בהתאם לרענון של Android. זהו בסיס מקומי לווידג׳טים, ולא שירות סנכרון Firebase ברקע.

## בדיקה ראשונה מומלצת

- צור הרגל עם שתי שעות קרובות, סמן **בוצע** בראשונה, וודא שהשנייה אינה מופיעה ושהמופעים של מחר נשארו.
- הוסף תיאור ארוך ובדוק הרחבת ההתראה ופתיחת התיאור בלחיצה.
- הוסף את שני הווידג׳טים ובדוק פתיחה, הוספה, סימון משימה ושינוי גודל.
- בנסיעה, סגור ופתח את האפליקציה ובדוק שהמרחק נשמר ושאותה תזכורת אינה חוזרת. אל תבצע את הבדיקה תוך כדי נהיגה.

הבנייה ובדיקות הנתונים והממשק בוצעו במחשב. אין עדיין אימות על טלפון פיזי של הווידג׳טים, קבלת מיקום ברקע, מסך ההתראות של היצרן או לחיצה אחרי אתחול.
