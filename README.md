# משימה

ניהול אישי: מסך "היום" שמאחד יומן ומשימות, משימות מקוננות ללא הגבלת עומק,
רשימות לפי סוג (שליחות · משאלות · רגילה), ותזכורות לפי **מיקום**, **מרחק נסיעה** ו**שעה**.
קובץ HTML אחד + מעטפת אנדרואיד דקה שנותנת geofencing אמיתי ברקע ושעון מעורר.

---

## מה צריך לעשות — פעם אחת

### שלב 1 · ליצור את הריפו

1. להיכנס ל-https://github.com ולפתוח חשבון (חינם).
2. **New repository** → שם: `mesima` → **Public** → Create.
   *חייב Public — רק ככה GitHub Pages ו-Actions חינמיים.*
3. **Add file → Upload files** → לגרור את כל התוכן של התיקייה הזאת → Commit.

### שלב 2 · האתר עולה לאוויר (פותר את בעיית המיקום)

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.

אחרי כדקה תהיה לך כתובת:
```
https://<שם-המשתמש>.github.io/mesima/
```
זו הכתובת שצריך לפתוח בטלפון. **רק ממנה** המיקום, ההתראות וההתקנה למסך הבית עובדים.
בכרום: ⋮ → **הוסף למסך הבית**.

> למה זה נדרש: קובץ שנפתח מההורדות נטען מ-`content://`, שהוא origin אטום.
> דפדפן חוסם שם מיקום לחלוטין — אין אפילו דיאלוג הרשאה, ולכן הגדרות הטלפון לא עוזרות.

## איך משנים משהו אחרי שהאפליקציה מותקנת

**לא בונים APK מחדש.** ה-APK הוא מעטפת דקה שכמעט לא משתנה; קוד האפליקציה נמשך מהאוויר.

```
משנים index.html  →  מעלים ל-GitHub  →  באפליקציה: עוד → "בדוק עדכון עכשיו"
```

האפליקציה מורידה את הקובץ, שומרת אותו פנימית וטוענת אותו. גם בפתיחה רגילה היא בודקת
ברקע, ואם ירדה גרסה חדשה מופיע בראש לשונית "עוד" פס ירוק עם כפתור טעינה.

בפעם הראשונה צריך להגדיר פעם אחת ב-**עוד → עדכון האפליקציה → כתובת המקור**:
```
https://<שם-המשתמש>.github.io/mesima/index.html
```

### למה זה לא שובר את הנתונים
כל התוכן מוגש דרך `WebViewAssetLoader` מ-origin וירטואלי קבוע:
`https://appassets.androidplatform.net/app/`.
זה origin מאובטח אמיתי מבחינת ה-WebView — ולכן מיקום, התראות ו-`localStorage` עובדים —
והוא **לעולם לא משתנה**, בין אם הקובץ הגיע מה-APK או מהרשת.
זו הנקודה הקריטית: טעינה ישירה מ-`https://user.github.io` הייתה יוצרת origin שני,
ואיתו `localStorage` שני — כלומר כל המשימות היו "נעלמות" בכל החלפת מקור.

רק בנייה מחדש של ה-APK נדרשת כששינוי נוגע ב**קוד הנייטיב** — גדרות מיקום, שעון,
הרשאות. לכל שאר השינויים מספיק להעלות קובץ.

---
### שלב 3 · ה-APK (רקע אמיתי + שעון מעורר)

נבנה לבד בכל פעם שמעלים שינוי. להורדה:
**Actions** → הבנייה האחרונה → **Artifacts → mesima-apk**,
או **Releases** → `mesima.apk` (נוח יותר מהטלפון).

להתקנה: לפתוח את ה-APK בטלפון ולאשר התקנה ממקור לא מוכר.
ה-APK חתום בחתימת debug — מספיק להתקנה אישית, לא לחנות.

### שלב 4 · ההגדרות שחייבים בגלקסי

בתוך האפליקציה → לשונית **עוד** → כרטיס **מצב האפליקציה**.
שלושת ה-✕ שם הם מה שמפריד בין "עובד" ל"שקט מוחלט":

| מה | למה |
|---|---|
| מיקום → **Allow all the time** | בלי הרשאת רקע אנדרואיד לא ירשום גדרות בכלל |
| התראות | בלי זה לא תראה כלום כשהאפליקציה סגורה |
| ללא הגבלת סוללה | בלי זה סמסונג מרדימה את האפליקציה |
| **Never sleeping apps** | סמסונג מכניסה אפליקציות ל"שינה" אחרי ~3 ימים ול"שינה עמוקה" אחרי ~16 |

יש כפתור באפליקציה שפותח כל אחד מהמסכים האלה ישירות.

## איך זה עובד מבפנים

### הרעיון המרכזי
תזכורות המיקום **לא** מנוהלות על ידי טיימר שלנו. הן נרשמות ב-`GeofencingClient`
של Play Services, ומערכת ההפעלה מחזיקה אותן. התהליך שלנו יכול להיות מת לגמרי —
אנדרואיד מעיר את `GeofenceReceiver`, וההתראה מפורסמת ישירות מ-Kotlin.

מכאן נובע: **אין foreground service, אין התראה קבועה, וצריכת סוללה אפסית.**

"הגעת + 15 דקות" ממומש ב-`GEOFENCE_TRANSITION_DWELL` עם `setLoiteringDelay(900000)` —
אנדרואיד סופר את ההמתנה בעצמו.

### מבנה
```
index.html                     ← כל האפליקציה. מקור אחד, משרת גם את GitHub Pages
android/
  app/src/main/
    assets/index.html          ← עותק שנוצר אוטומטית בבנייה
    java/il/mesima/app/
      MainActivity.kt          WebView + זרימת ההרשאות הדו-שלבית
      WebBridge.kt             window.MesimaNative — הגשר ל-JS
      Fences.kt                עטיפת GeofencingClient + שמירה ורישום מחדש
      GeofenceReceiver.kt      רץ כשהאפליקציה מתה. מפרסם התראה נייטיבית
      BootReceiver.kt          רישום מחדש אחרי אתחול/עדכון
      Notif.kt                 ערוץ והתראות
.github/workflows/android.yml  ← בונה APK בענן
```

מודולים ב-JS: `Store` (נתונים) · `Geo` (מרחקים ונסיעה) · `Search` (חיפוש מקומות) ·
`Alerts` · `Cal` · `Native` (הגשר) · `UI`/`Wire` · `Engine` (מנוע התזכורות).
להוספת סנכרון בין מכשירים בעתיד — מחליפים את `Store` בלבד.

### דברים שדפדפן לא יכול, ולכן קיים ה-APK
- **מעקב מיקום כשהאפליקציה סגורה.** `Geolocation` מוגדר `[Exposed=Window]` ואינו קיים
  ב-Service Worker; המפרט מגביל עדכוני מיקום למסמכים **גלויים** בלבד.
  Periodic Background Sync רץ פעם ב-12–36 שעות ואין בו גישה למיקום.
  `w3c/geofencing-api` נארכב ב-2019.
- **כתיבה לשעון של הטלפון.** Chrome מוסיף בכפייה `CATEGORY_BROWSABLE` לכל `intent://`
  ומנקה `component`, ואפליקציות השעון לא מצהירות עליו. בנוסף נדרשת ההרשאה
  `com.android.alarm.permission.SET_ALARM`, שדפדפן לא מחזיק.

## מה יש באפליקציה

### היום — מסך הבית
היום שלך במבט אחד: אירועי היומן והמשימות שתוכננו ליום, ממוזגים לפי שעה עם קו "עכשיו".
הכפתורים **היום / מחר / תאריך** מזיזים את התצוגה — ובזה בדיוק מתכננים את מחר.
`↳ שלוף ממשימות קיימות` פותח בורר שמושך משימות קיימות אל היום הנבחר.
אירוע שנוסף ביומן מופיע כאן אוטומטית.

### משימות — קינון ללא הגבלה
משימה קטנה נשארת שורה אחת. משימה גדולה נפתחת: ⋯ → **תת-משימה חדשה**, וכל תת-משימה
יכולה להכיל תת-משימות משלה, בלי תקרה. **אין בר התקדמות** — רק מונה "N בפנים",
משולש לקיפול, וקו הזחה שמראה את המבנה.
סגירת משימה סוגרת את כל העץ שמתחתיה, כדי שלא יישארו תתי-משימות פתוחות ובלתי נראות.

### רשימות — שלושה סוגים, לכל אחד התנהגות משלו

| סוג | בשביל מה | מה מיוחד בו |
|---|---|---|
| **רגילה** | קניות שוטפות | פריטים עם חנות, קישור ותמונה. מזין את המסלול המומלץ |
| **שליחות** | "אמא שלחה אותי לקניות" | סוגר חשבון בסוף ושולח הודעה מפורטת |
| **משאלות** | ספרים/משחקים שאתה רוצה | מפריד "אפשר לקנות" מ"עוד לא יצאו", עם תאריך יציאה והתראה |

**סגירת חשבון (שליחות):** בסיום — שאלה אם שילמת מכספך, שדה מחיר לכל פריט עם סכימה
אוטומטית, ואז הודעה מוכנה עם הפירוט והסכום שנשלחת בוואטסאפ (הטלפון מנורמל ל-972)
או מועתקת. אחריה נשאלת אם למחוק את הרשימה.

**מעקב יציאה (משאלות):** לספרים יש בדיקה אוטומטית מול Google Books — כפתור "בדוק יציאה"
מוצא תאריך פרסום ואפשר לקבוע אותו בלחיצה. **למשחקים אין מאגר חינמי שדפדפן יכול לפנות
אליו ישירות**, ולכן שם הבדיקה היא קישור חיפוש. כשתאריך היציאה מגיע — התראה.

תמונות מכווצות ל-320px לפני שמירה; בלי זה תמונה אחת מהמצלמה ממלאת את מכסת האחסון.

## פיתוח מקומי

```bash
python3 -m http.server 8000     # ואז http://localhost:8000
```
`localhost` נחשב origin מאובטח, ולכן המיקום וההתראות עובדים בפיתוח בלי אחסון.

לבנייה מקומית של ה-APK צריך JDK 17 + Android SDK 35:
```bash
cp index.html android/app/src/main/assets/index.html
cd android && gradle assembleDebug
```
